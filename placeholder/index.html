Inventario Multinyectores

Plataforma para gestionar inventarios, ventas y facturación

Descripción general

Inventario Multinyectores es una aplicación web diseñada para manejar el ciclo completo de ventas y stock: desde la creación y coste de productos, control de almacenes, facturación y reportes analíticos para la toma de decisiones.

Módulos principales

  • Productos: catálogo con múltiples precios, costos y estados (activo/archivado).
  • Almacenes: gestión de existencias por ubicación.
  • Ventas: crear ventas, aplicar pagos, generar facturas y notas de crédito.
  • Clientes: historial de compras y datos de facturación.
  • Reportes: ranking de ventas, alertas de stock bajo y análisis por categoría.
  • Usuarios y roles: permisos por rol (admin, vendedor, lector).

Flujo típico

  1. Registrar productos y definir costos/precios por almacén.
  2. Registrar clientes y crear ventas desde el POS o facturación.
  3. Generar facturas y llevar el control de pagos.
  4. Usar reportes para identificar top productos y alertas de stock.

Tecnología

Backend: Node.js + Express + Sequelize (MySQL). Frontend: React (react-scripts). Opcional: docker-compose para despliegues.

Credenciales de prueba

Si instala la base de datos de ejemplo o crea usuarios, puede usar (ejemplo):

  • Administrador: admin@example.com / Admin123!
  • Vendedor: vendedor@example.com / Vendedor123!

Requisitos y despliegue rápido

  • Servidor VPS Ubuntu 22.04+, Node.js 18/20 y MySQL.
  • Instalar dependencias: npm install en backend y frontend.
  • Construir frontend: npm run build y copiar build/ a /var/www/inventario.
  • Ejecutar backend con pm2 start app.js y configurar proxy en nginx.
  • Obtener SSL con Let's Encrypt: certbot --nginx.
